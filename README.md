# 🛡️ ENICRAY — Anti-Scam Download Verifier

Curiously looking for a certain famous console file (wink, wink) and don't want to get your accounts stolen by fake malware?

**ENICRAY** is a free, open-source browser extension for Chrome, Brave, and Edge that inspects files **before** you open them, verifies their digital fingerprint (SHA-256), and catches tampered or junk-inflated fakes.

###  What does it do?
* **Checks if it's the authentic file:** Automatically verifies if the `.zip` or `.exe` matches the unedited original fingerprint (and reminds you it's an Xbox console binary, not playable on Windows).
* **Catches fake traps:** Triggers an immediate red alert if a file pretends to be the leak with a mismatched hash or is padded with gigabytes of junk data.
* **100% Private & Local:** Everything runs locally inside your browser. None of your files are ever uploaded anywhere.

###  How to install in 30 seconds
1. Go to the **Releases** section (on the right side of this page) and download the latest `.zip` file (or click the green **Code → Download ZIP** button).
2. Extract the folder anywhere on your PC.
3. Open Chrome, Brave, or Edge and go to: `chrome://extensions/`
4. Turn on **Developer mode** (top right corner).
5. Click **Load unpacked** and select the extracted **ENICRAY** folder.
